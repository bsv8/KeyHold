# 密码与密码学

KeyHold 使用 PBKDF2-HMAC-SHA-256 从 UTF-8 密码派生 256 位密钥，使用 16 字节随机盐和推荐的 600,000 次迭代。AES-256-GCM 使用随机 12 字节 IV 和 128 位认证标签加密 32 字节 secp256k1 私钥。

参数明确写入文档，因此其他实现可以复现派生过程并验证密文。SDK 仍会针对支持的算法和长度约束验证每个参数。

密码管理由应用负责：使用安全输入路径，避免写入日志，并在流程允许时尽快丢弃明文密钥材料。
