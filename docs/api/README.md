# API Reference

KeyHold publishes API references for both SDKs:

- TypeScript: generated with TypeDoc into `docs/api/typescript/`.
- Go: generated by Go’s package documentation tooling and published at
  [pkg.go.dev/github.com/bsv8/KeyHold/go/v2](https://pkg.go.dev/github.com/bsv8/KeyHold/go/v2).

Run both local documentation checks with:

```sh
make docs
```

The TypeScript reference is generated locally because it is a static HTML
site. Go’s canonical reference is `pkg.go.dev`, which renders the exported
package documentation directly from the tagged Go module.
